# Scheduling

The scheduling API creates, pauses, resumes, deletes, and lists
recurring workflow runs. See the
[Scheduled Workflows guide](/guides/scheduling) for the conceptual
walk-through with examples.

```python
await schedule_workflow(DataSyncWorkflow, schedule_name="hourly", schedule="0 * * * *")
await schedule_workflow(DataSyncWorkflow, schedule_name="fast", schedule=timedelta(minutes=5))
```
